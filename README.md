## Engenharia de Requisitos e Modelagem - MYPLAN

Projeto de análise e engenharia de requisitos para uma aplicação web de plano de cortes de cabelo em uma barbearia.

### Arquivos
* **reuniao_inicial.md:** Aqui está registrado a etapa inicial da análise de requisitos, onde foi feito a reunião com o cliente para fazer os levantamentos das necessidades e objetivos dele junto a aplicação.
* **elicitacao-requisitos.md:** Aqui foi extraido os requisitos funcionais e não funcionais da reuniao inicial.
